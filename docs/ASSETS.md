# Asset provenance

Shadowfetch Blackjack ships no third-party casino branding, music, sound effects, fonts, models, or texture packs.

- Card faces and card back: original raster artwork stored in `assets/cards/`.
- Table, furniture, chips, shoe, tray, discard, lighting, and markings: original procedural Godot geometry and materials generated by `scripts/table/`.
- Interface and effects: original procedural Godot controls and particles.
- Audio: PCM generated at runtime from original synthesis routines in `scripts/audio/audio_manager.gd`; no sampled recordings are bundled.
- Application icon: original Shadowfetch Blackjack artwork in `icon.svg`.
- Documentation screenshots: captured from the actual Linux Vulkan build.
